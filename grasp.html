Grasp

Generating grasp poses is a crucial component for robot object manipulation tasks. Here we aspire to build a framework that optimize motion planning and grasp planning jointly. This planner would integrate the four main tasks needed for grasping an object: building a feasible grasp set, selecting the best grasp, solving the inverse kinematics problem, and determining a collision-free trajectory. Previous trajectory optimization methods such as CHOMP offers goal set variant and GPMP2 offers fast replanning methods. We are interested in leveraging the diverse grasp set to improve the local minimum issues in previous work.
