6D Object Pose Tracking with the Deep Iterative Matching Network

Abstract

    Pose estimation has been studied extensively by computer vision and robotics researchers. While direct pose regression from RGB image is limited by various factors, DeepIM (Deep Iterative Matching) aims to iteratively refine the pose by matching the rendered image against the observed image by predicting a relative untangled pose transformation.. This project mainly addresses the performance of DeepIM on YCB dataset and tracking tasks. We trained the network using only synthetic data and applied it to 6D pose tracking of YCB objects. By propagating the pose estimate from the previous frame to the current frame, DeepIM is able to track robot hand and object poses under heavy occlusion with no real world finetuning and any calibration process.
