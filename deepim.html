DeepIM

DeepIM aims to iteratively refine the pose by matching the rendered image against the observed image by predicting a relative untangled pose transformation. Here we trained the network using only synthetic data and applied it to tracking tasks. By propagating the pose estimate from the previous frame to the current frame, DeepIM is able to track robot hand and object poses under heavy occlusion.
